<h1 align="center">Köprü</h1>
<p align="center">Hızlı, güvenli ve kendi sunucunuzda çalışan uzak masaüstü programı</p>

## İndir

**Windows:** [Kopru.exe](../../releases/latest/download/Kopru.exe)

Kurulum gerektirmez: indirip çalıştırmanız yeterli. Kalıcı kurulum için program içindeki **Kur** düğmesini kullanabilirsiniz.

## Özellikler

- Uçtan uca şifreli uzak masaüstü bağlantısı
- Gözetimsiz erişim (kalıcı şifre, Windows açılışında otomatik çalışma)
- Dosya transferi
- Sohbet ve sesli görüşme
- Adres defteri
